# Sajil Binu — Portfolio Matrix

An interactive, high-performance portfolio featuring a 300-frame cinematic scroll sequence, dynamic sidecard parallax physics, and the "Old Town Road" soundtrack.

## 🚀 Features
- **Cinematic Canvas Scrubbing:** 300 high-DPI frames dynamically scrubbed via smooth scroll interpolation.
- **Dynamic Scroll-Driven Parallax Sidecards:** Left and right skill & project cards float and breathe in real time with scroll velocity inertia.
- **Old Town Road Soundtrack Engine:** Integrated background soundtrack player with animated equalizer bars, auto-start on interaction, and toggle controls.
- **Glassmorphic HUD:** Cyberpunk / modern glass UI with chapter navigation and responsive layouts.

## 🛠️ Stack
- HTML5 / CSS3 (Modern Glassmorphism & Custom Properties)
- Vanilla JavaScript (RequestAnimationFrame physics & Audio Engine)
- HTML5 Canvas 2D Rendering

## 💻 Running Locally
You can run this project with any local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node / npx
npx serve
```

Then visit `http://localhost:8000` in your browser.
